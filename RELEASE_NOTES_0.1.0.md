# BR-GOGImport v0.1.0 Experimental

- Import an owned GOG library into BOXROOM using batched metadata requests.
- Locate BOXROOM's cache automatically on Windows and Linux/Proton.
- Show one compact count-based progress line instead of verbose per-file output.
- Warn clearly that the importer is experimental before it starts.
- Remind users to paste the full GOG redirect URL after browser sign-in.
- Add GOG Galaxy launch metadata and migrate existing imported entries.

This release is experimental. Linux and Proton behavior has not been validated live on Steam Deck.
